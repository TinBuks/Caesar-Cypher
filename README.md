Creating a Caesar Cypher in Javascript for use translating text into Caesar Code as well as translating it out. If you test this, try putting in 13 as your shift, typing your message and then copy/pasting the translated code into the text box again. Made 5 months ago.

Caesar Cypher shifts the entire Alphabet a certain amount of spaces, which makes it not great for actually making secret messages as it is very easy to identify. Still, it was a good learning project.
